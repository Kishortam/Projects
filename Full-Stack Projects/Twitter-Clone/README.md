# TWITTER / X CLONE APP

**About Project**
* item Built a full-stack social media application using the MERN stack with essential features like post creation (text, image, or both), liking/unliking posts, commenting, and post deletion(owner-only).
* Users can follow others, view their posts, update/edit profiles, and upload profile/cover images. 
* The app includes a Twitter-like post/likes toggle, real-time notifications, and a fully responsive UI.
* React.js, Tailwind CSS + DaisyUI for styling. Node.js, Express.js with MongoDB as the database. JSON Web Tokens (JWT) for secure authentication. Integrated Cloudinary for media storage.
* React Query (Tenstack) for data fetching, caching, and updates.
* JSON Web Tokens (JWT) for secure authentication. Integrated Cloudinary for media storage.


**Setup .env file**
* MONGO_URI=...
* PORT=...
* JWT_SECRET=...
* NODE_ENV=...
* CLOUDINARY_CLOUD_NAME=...
* CLOUDINARY_API_KEY=...
* CLOUDINARY_API_SECRET=...

**Build the app**
* npm run build

**Start the app**
* npm run start
