Twitter Clone App:

=> Fundamental concepts of social media app like: 
1. create a post, which can be both text and image.
2. like/unlike, comment on it.
3. if you are user, you can delete post.
4. send notifications of like and comments of post, delete notifications.
5. update profile image, cover image, profile info etc.
6. we can follow users from suggested users panel
7. login, logout, signup with authentication.

for the UI design of app => Tailwind CSS and DaisyUI
data fetching, caching, updating and invalidating => tanstack_query

Part 1: Backend (JS & Express)
=> Project setup (mongoDB)
=> Authentication (JWT)
=> User Controllers (Postman & VS)
=> Post Controllers (Postman & VS)
=> Notification Controllers (Postman & VS)

Part 2: UI Design (React & Tailwind, DaisyUI)
=> Hard coded Data (Basic UI)
=> React-Router-Dom (Navigation)

Part 3: Connect (React & TanstackQuery)
=> Queries
=> Mutations
=> Hooks

Part 4: Deploy
=> Setup the server
=> render.com

Start Coding =>

=> Create front-end and backend folders in Main folder.
=> Create a react app with vite in frontend folder, install node module and dependencies.

=> Open terminal for main folder/root, in terminal we write -> npm init -y to add dependencies.
=> Install all dependencies and packages at one go -> 
npm install express mongoose jsonwebtoken bcryptjs dotenv cors cookie-parser cloudinary
=> install -D nodemon

=> in packeage.json make following changes:
*  "main": "backend/server.js", // change file name from index.js to server,js
* "scripts": {
    "dev": "nodemon backend/server.js",  // npm run dev command to start with browser
    "start": "node backend/server.js",
  },
* "type": "module", // right after author

=> to check if all is working good, create a server.js file in Backend folder, write code for console.log("any text"), in terminal write npm run dev to see node is working.

=> start with server.js in backend folder
=> Create routes (for navigation), controller (functions), and model (schema) folders and files.
=> start with mongoDB 


//-------/-----------

Frontend: go to frontend and run npm run dev
=> create a pages folder under src -> auth -> Home, login, notifications, signup 
=> src -> profile -> profilePage, editProfile modal.

before deployment:
=> in package.json -> scripts -> 
"scripts": {
    "dev": "NODE_ENV=development nodemon backend/server.js",
    "start": "NODE_ENV=production node backend/server.js",
    "build": "npm install && npm install --prefix frontend && npm run build --prefix frontend"
  },

=> in server.js
if(process.env.NODE_ENV === "production"){
    app.use(express.static(path.join(__dirname, "/frontend/dist")));

    app.get("*", (req, res) =>{
        res.sendFile(path.resolve(__dirname, "frontend", "dist", "index.html"));
    })
}

=> terminal of root folder : npm run build
