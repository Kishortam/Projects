frontend:
=> create app with vite
=> change port name if u want in vite.config.js
=> install tailwind css
=> install react-router-dom react-hot-toast react-icons
=> setup react-router-dom with browserRoute in main.js
=> add routes for pages in app.js
=> create pages and components
=> get a github api to fetch the data -> api.github.com -> users {users} , repos_url
=> add toaster and import in app.jsx to get toast notification

backend:
=> setting up the server, in root folder npm init -y, to add package
=> install express mongoose dotenv cors
=> create server.js
=> create .env file and add mongodb url
=> install nodemon for dev dependencies
=> in package.json add dev script and module type to import packages.
