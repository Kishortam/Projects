# GITHUB CLONE APP

**About the app**
* Developed a GitHub-like application using the MERN stack, Tailwind CSS, and the GitHub API to fetch and display user-profiles and repositories
* Implemented sorting and filtering based on date, stars, and forks, along with clone URL copying for easy repository access.
* Integrated Passport.js authentication for GitHub-based signup and MongoDB (Mongoose) for database management. Ensure a seamless and responsive experience.
* Improved user interaction with client-side validation and real-time error handling.
